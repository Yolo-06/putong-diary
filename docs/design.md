# 噗通日记本 V4.1 — 少女治愈系设计文档 🎀

## 0. 数据模型

### 0.1 记账记录（records）
```js
{
  id: 1626000000000,           // 时间戳ID
  amount: 35.00,               // 金额
  cat1: '🍽️ 餐饮饮食',         // 一级分类
  cat2: '午餐',                // 二级分类
  date: '2026-07-14',          // 日期
  note: '打字小爪爪...',        // 备注(碎碎念)
  type: 'expense',             // expense / income（由 recordType 决定）
  photos: ['data:image/jpeg;base64,...']  // 照片数组(压缩后,最多9张)
}
```

### 0.2 治愈手账（journals）
```js
{
  id: 1626000000000,
  content: '今天和姐妹打卡了超可爱的猫咪咖啡厅！...',
  photos: ['data:image/jpeg;base64,...'],  // 最多9张
  mood: '🥰',        // 🥰超幸福 / 🐶元气 / 🥺委屈 / 🥱困困 / 🐱傲娇 / 💔碎碎念
  sticker: '🌸',     // 电子贴纸装饰
  relatedRecordId: 1626000001, // 关联账单ID (null=纯手账)
  date: '2026-07-14',
  time: '15:40',
  createdAt: '2026-07-14T15:40:00.000Z'
}
```

### 0.3 其他存储
```js
var monthlyBudget = 5000;       // 月度预算(默认5000,可修改)
var quickActions = [...];        // 快捷记账按钮配置
var userCategories = {...};      // 用户自定义分类
var userColorOptions = [...];    // 15种可选颜色
```

### 0.4 localStorage 键名一览（V2，已废弃 ⚠️）

> ⚠️ V3.0 起数据曾迁移到 SQLite 数据库（`data.db`）。**V4.2 起数据已改为云端 Neon PostgreSQL 永久存储**（见 `.env` 的 `DATABASE_URL`），根目录 `data.db` 是早期版本遗留文件，可忽略或删除。localStorage 继续作为每用户的本地备份使用，键名加用户名前缀：`{username}_jizhangben_records`。
> 以下为 V2 时代键名，仅作历史参考。

| 键名（V2旧版） | 存储内容 | 说明 |
|------|----------|------|
| `jizhangben_records` | 记账记录数组 | JSON格式 |
| `jizhangben_journals` | 手账记录数组 | JSON格式 |
| `jizhangben_usercats` | 用户自定义分类 | JSON格式 |
| `jizhangben_budget` | 月度预算金额 | 纯数字 |

## 3. 各页面详细设计

### 3.0 锁屏登录页（#lockScreen）— V4.1 重构

**布局（从上到下）**：
1. **猫咪图标**：`<img src="assets/black-cat.png">` 替代原来的 🐱 emoji，108×108px，圆角24px，粉色光晕阴影，浮动动画
2. **标题**："✨ 噗通日记本"
3. **登录/注册切换标签**：`.lock-tabs` 水平并排两个按钮（"登录"/"注册"），选中态粉色渐变高亮
4. **昵称输入**：200px 宽居中，圆角14px，粉色边框，placeholder "给自己取个昵称~"
5. **密码红点**：`.pin-dots` 6个圆点，已输入变实心粉色
6. **数字键盘**：`.pin-keypad` 3×4+1 布局，右下"进入"按钮
7. **底部辅助**：忘记密码链接 / 注册入口

**交互细节**：
- **自动提交**：输入满6位密码后自动触发 `onPinGo()`，无需手动按"进入"
- **进入按钮高亮**：密码输满时按钮放大1.06倍+亮度提升（`.go-ready`），视觉反馈
- **登录欢迎**：如果localStorage存有上次昵称，登录时显示"欢迎回来，XXX 🐱"
- **轻提示 vs 错误提示**：
  - `showPinHint(msg)`：轻提示，显示1.8秒后消失，**不抖动、不清空已输密码**
  - `showPinError(msg)`：错误提示，密码容器抖动+清空输入
- **注册/登录切换**：`switchToRegister()` / `switchToLogin()`，tab标签同步高亮

### 3.1 治愈首页（page-home）

**结构（从上到下）**：
1. **轮播图**：3张便利贴风格卡片，自动轮播3.5秒，随机治愈语录+今日数据
2. **手账闪电入口**：草莓粉渐变卡片，虚线边框，"收集今天的小确幸吧！→ 📷 贴张照片 / 码字"
3. **碎碎念时间轴**：今日手账卡片列表，拍立得相片风格，最多显示4张照片缩略图
4. **快捷记账**：🍱干饭 ☕奶茶 🛍️买买 🚇贴贴（4个软糖按钮，4种不同浅色背景）
5. **盲盒+时光机**：🎁 拆盲盒 / 🔮 旧时光 两个小按钮并排居中
6. **预算提醒**（条件显示）：超80%黄色卡片，超100%粉色卡片
7. **小钱包概览**：🌸倒出钱包 / 🍓喂给生活 / 🌟剩余宝藏

**轮播卡片配色**：
- 第1张：`#FFF0F3`（粉色底）— 显示今日花销 + 碎碎念条数
- 第2张：`#F0F8F4`（绿色底）— 显示比上月多花/少花 + 本月收支
- 第3张：`#F8F0FB`（紫色底）— 显示坚持记录天数

### 3.2 记账页（page-add）— 双色拼盘+软糖键盘

**双色拼盘布局**：
- **上半部分**：蜜桃草莓粉弧形区（`linear-gradient(180deg, #FFB7C5 0%, #FF9AA2 100%)`），`border-radius: 0 0 24px 24px`，含花瓣支出/收入切换 + 大号金额展示（36px白色粗体+阴影）+ 已选分类标签
- **下半部分**：棉花糖白底卡片区，`border-radius: 20px 20px 0 0`，`margin-top: -8px` 覆盖粉色区，`box-shadow: 0 -4px 20px rgba(255,183,197,0.15)`

**内容区（从上到下）**：
1. **花瓣类型切换**：🌸支出 / 🌟收入，半透明白底圆角标签（`rgba(255,255,255,0.25)` 底），选中白色高亮
2. **分类圆糖**：3列网格，每个38px圆形包裹图标，选中时放大1.15倍+旋转-3°+粉色阴影；默认折叠，点击"👛 钱钱去哪了？"展开
3. **二级分类**：下拉选择框
4. **气泡输入**：日期+备注，粉色虚线边框（`2px dashed #FFB7C5`），聚焦变实线
5. **拍立得照片区**：72x72px缩略图，3px白边+阴影，日系胶片滤镜（`brightness(1.05) saturate(0.9)`）
6. **软糖数字键盘**：CSS Grid 4列×4行布局（见 §8.6）
7. **保存后猫咪邀请**：800ms后弹出对话框"要顺便写手账吗？(=·ω·=)"

**金额输入**：不绑定 DOM input，使用 `kbAmount` 变量 + 软糖键盘输入，显示在粉色区域。

**记账成功后流程**：
1. `spawnCoinRain()` — 15个 emoji 软糖落雨
2. 桌宠冒泡 💰
3. 800ms 后弹出猫咪手账邀请弹窗
4. 可点"📝 去写手账"→ 自动关联刚保存的记账记录

### 3.3 手账编辑页（弹窗）

1. **信纸文本框**：横线格子背景（`repeating-linear-gradient`），4行高
2. **心情选择**：🥰🐶🥺🥱🐱💔 6个表情，选中放大1.3倍+全不透明

### 3.4 账单与统计页（page-bills）— 二合一

**列表视图**（默认）：
- 月份切换（◀ ▶）+ 月份标签 + 📊魔法统计按钮
- 月度汇总条：🌸倒出钱包 / 🍓喂给生活 / 🌟剩余宝藏

**统计视图**（点 📊魔法统计 切换，列表隐藏）：

- 🌈 本月心情晴雨表：各心情占比条形图（🥰超幸福/🐶元气/🥺委屈/🥱困困/🐱傲娇/💔碎碎念）
- 点 📋账单 切回列表

### 3.5 治愈时刻（page-heal）— 数据聚合仪表盘

底部第4个标签"🌟治愈"，首次进入时计算全量历史数据：

1. **治愈语录**：随机展示一条粉紫渐变色卡片（`linear-gradient(135deg, var(--pink-light), var(--lavender-light))`）

2. **2×2数据卡片**（`.heal-stat-grid`，CSS Grid）：
   - 📝 手账纪念册：总篇数 + 总照片数（journals照片 + records照片）
   - 📅 坚持的力量：累计记账天数（去重 `new Set(records.map(r=>r.date)).size`）+ 子标题"打卡了 X 个日子"
   - 🥰 心情之王：最常出现的心情emoji + 名称 + "出现了 X 次"
   - 🐱 吞金兽TOP3：支出最多分类排行，整行大卡（`grid-column: 1 / -1`），带排名徽章+颜色+金额

3. **照片回忆墙**：收集所有 journal + record 照片，随机打乱取9张，3×3网格；不足9张用🌸虚线空格填充

4. **心情甜甜圈**：SVG环形图（200×200 viewBox，半径70，stroke-width 18），6种心情各一段弧，用 `stroke-dasharray` + `transform: rotate()` 实现；中心显示心情之王emoji；下方图例标注百分比

5. **连续记账里程碑**：从今天往前数连续记账天数 + 成就emoji（7天🌟/30天👑/100天💎）+ 治愈鼓励文案
