# 噗通日记本 — 项目说明文档

## 产品信息

- **APP 名称**：✨ 噗通日记本（V4.1）
- **运行平台**：Windows 电脑
- **使用方式**：先运行 `node server.js`，再打开浏览器访问 `http://localhost:3456`
- **货币单位**：人民币（¥）
- **技术方案**：前端 HTML+CSS+JS（单文件 `index.html`），后端 Node.js + Express（`server.js`），数据存 Neon 云端 PostgreSQL（连接字符串存在 `.env` 的 `DATABASE_URL`）

## 核心功能

1. **密码锁屏**：6 位数字密码保护隐私，支持修改、忘记重置（限频保护）和退出登录
2. **记账**：双色拼盘 + 软糖数字键盘，支持照片上传（最多9张），支出/收入切换
3. **手账**：文字+照片+心情+贴纸，可与账单击联
4. **首页**：轮播图、碎碎念时间轴、快捷记账、盲盒签到、时光机、预算提醒
5. **账单+统计**：按月份筛选记录，分类条形图、月度趋势折线图、心情晴雨表
6. **治愈时刻**：数据仪表盘，手账纪念册、坚持天数、心情甜甜圈、照片回忆墙
7. **导出备份**：CSV 导出（Excel 可打开）、完整 JSON 备份（含照片）
8. **数据持久化**：Neon 云端 PostgreSQL 永久存储，重启/重新部署都不丢数据
9. **暗黑模式**："芋泥星愿"夜间主题，毛玻璃卡片效果
10. **电子桌宠**：右下角浮动萌宠，支持自定义猫咪图片
11. **许愿储钱罐**：存钱打卡计划，每天投币，草莓日历追踪进度，21:00 提醒
12. **临时自定义分类**：记账时可随时输入临时分类名，无需去设置永久添加
13. **黑猫图标系统**：锁屏页和页面中猫咪emoji替换为定制黑猫图片，透明背景干净利落
14. **静态资源托管**：`assets/` 目录通过 Express 托管，图片路径 `/assets/black-cat.png`
15. **多用户系统**：昵称+6位密码注册登录，每人独立数据空间（user_id 隔离）
16. **退出登录**：设置面板一键注销，清空本地数据，安全切换账号
17. **密码重置限频**：同一用户名 5 分钟内仅允许 1 次重置，防恶意清空数据

## 项目开发规则（重要！必须遵守）

### 用户背景
- 用户**不懂编程技术**，是技术小白
- 用户**首次使用 Claude Code**
- 用户无法自行提供技术方案或细节要求

### 核心规则
1. **所有技术决策**：必须由 Claude 列出 2-4 个方案，用通俗易懂的语言解释每个方案的优劣势，让用户选择决定
2. **禁止假设用户懂技术**：解释时避免使用专业术语，如果必须使用，要用生活化的比喻加以说明
3. **每一步都确认**：在动手写代码或做修改之前，先让用户确认方案和方向
4. **主动提醒**：当涉及数据安全、功能取舍等重要决策时，主动提醒用户注意风险
5. **语言通俗**：所有沟通使用日常用语，不预设用户了解任何编程概念

- ❌ 错误："我们用 IndexedDB 做持久化存储，用 Chart.js 做可视化"
