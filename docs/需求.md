# 噗通日记本 V4.1 — 需求文档

## 概述

将记账本从纯浏览器应用升级为"**后端数据库 + 密码保护**"的安全应用。V2.0 已经实现了记账+手账二合一的可爱风应用，V3.0 重点解决数据安全和隐私保护。

## V3.0 新增需求

### 13. 本地数据库后端（SQLite）

**需求**：数据不再存浏览器 localStorage，改为存硬盘上的 SQLite 数据库文件。

**原因**：
- localStorage 跟浏览器网址绑定，换端口/协议数据就找不到
- 清浏览器缓存数据全丢
- 数据库文件是实实在在的硬盘文件，可以备份到U盘

**实现**：
- Node.js 后端服务（`server.js`），提供 REST API
- SQLite 数据库文件（`data.db`），5 张表
- 首次启动自动迁移旧 localStorage 数据
- 启动方式：先 `node server.js`，再打开浏览器

### 14. 密码锁屏

**需求**：打开应用首先看到密码输入画面，输入正确才能进入。

**详情**：
- 首次使用：设置 4~6 位数字密码
- 后续使用：输入密码登录
- 登录后点数动态匹配密码长度（4位就显示4个点）
- 设置面板中可修改密码（需验旧密码）
- 登录页底部"忘记密码？"链接，输入确认短语后可重置（数据保留）

### 15. 暗黑模式 "芋泥星愿"

**需求**：切换夜间模式，保护眼睛。

**详情**：

### 16. 电子桌宠

**需求**：右下角浮动萌宠，增加陪伴感。

**详情**：

### 17. 盲盒签到

**详情**：

### 18. 治愈时刻页面

**需求**：数据聚合仪表盘，回顾记账历程。

**详情**：
- 随机治愈语录
- 手账纪念册（总篇数 + 照片数）
- 坚持的力量（累计记账天数 + 连续天数）
- 心情之王（最常见心情）
- 吞金兽 TOP3（支出最多分类）
- 照片回忆墙（随机 9 张）
- 心情甜甜圈（SVG 环形图）

### 19. 安全加固

**需求**：V3.0 安全审计后修复的隐患。

**详情**：
- 关闭 data.db 直接下载漏洞
- XSS 注入修复（分类名转义）
- 密码重置需输入确认短语
- 修改密码需验证旧密码
- JSON 请求体限制从 50MB 降至 10MB

## 数据存储

### V3.0：SQLite 数据库（`data.db`）

| 表 | 存储内容 |
|------|------|
| `records` | 记账记录（id, amount, cat1, cat2, date, note, type, photos） |
| `journals` | 手账记录（id, content, photos, mood, sticker, related_record_id, date, time, created_at） |
| `user_categories` | 用户自定义分类（name, subs, color） |
| `kv_store` | 键值存储（password_hash, pin_length, budget, darkmode, stickers, checkin_date, pet_img） |
| `sessions` | 登录会话（token, created_at） |

### V2.0（旧）→ V3.0 迁移

旧 localStorage 数据在首次启动时自动迁移到 SQLite，不删除旧数据。

## V4.0 新增需求

### 24. 多用户注册/登录系统

**需求**：每人用昵称+密码创建独立账号，数据互不干扰。

**详情**：
- 注册：昵称（3-20位，支持字母数字中文下划线）+ 6位数字密码
- 登录：输入昵称和密码，服务端验证后返回 Token 会话
- 所有7张数据表新增 `user_id` 列，SQL 查询全带 `WHERE user_id = ?`
- bcryptjs 10轮哈希存储密码，`crypto.randomBytes(32)` 生成 Token
- 登录状态持久化：Token 存 localStorage，关浏览器重开不丢失

### 25. 退出登录

**需求**：设置面板提供退出登录按钮，安全切换账号。

**详情**：
- 退出时 `localStorage.clear()` 清空所有本地数据
- 通知服务器 `POST /api/auth/logout` 销毁 Token
- 刷新页面回到锁屏，不会残留上一个账号的数据

### 26. 修改密码

**需求**：登录后可修改自己的密码。

**详情**：
- 设置面板"修改密码"入口
- 需验证旧密码，新密码限 6 位纯数字
- 通过 `PUT /api/auth/change-password` 更新

### 27. 密码重置

**需求**：忘记密码时可以重置账号。

**详情**：
- 锁屏页"忘记密码？"链接
- 无需登录即可重置（因为忘记密码无法登录）
- **安全保护**：同一用户名 5 分钟内最多 1 次重置请求（返回 429）
- 重置后该用户所有数据清空，需重新注册

### 28. 多用户数据隔离

**需求**：用户 A 看不到用户 B 的记账记录、手账、分类、储钱罐等数据。

**详情**：
- 服务端 `requireAuth` 中间件从 Token 解析 `user_id`
- 所有 GET/PUT/POST 操作按 `user_id` 过滤和写入
- 客户端 localStorage 备份按用户名隔离：`{username}_jizhangben_records`
- 刚注册新账号（`justRegistered` 标记）不会自动恢复旧备份，防止串数据

### 29. 云端部署（Render）

**需求**：项目部署到公网，手机/电脑都能访问。

**详情**：
- 部署平台：Render 免费套餐（Node.js + 临时磁盘）
- 服务端监听 `HOST=0.0.0.0`、`PORT` 由环境变量控制
- GitHub 代码推送后需手动 "Deploy latest commit"
- Render 免费套餐数据不持久，通过 localStorage 自动备份+恢复缓解

### 30. 记住登录 + 数据本地备份

**需求**：关闭浏览器再打开不用重新登录，服务器数据丢失时自动恢复。

**详情**：
- Token 存 localStorage（非 sessionStorage），关浏览器不丢
- 记账、手账、分类保存时同步写一份到 localStorage
- 加载数据时若服务器为空，自动从 localStorage 恢复
- 储钱罐数据也有独立备份 `{username}_savings_backup`

## V4.1 新增需求

### 24. 黑猫图标系统

**需求**：锁屏页和全局猫咪emoji替换为定制黑猫图片，不再使用emoji。

**详情**：
- 用户提供透明背景猫咪图片（`retouch_2026080219391608.png`）
- 处理后生成两个版本：`black-cat.png`（锁屏108px图标）、`black-cat-emoji.png`（行内替换用）
- 所有页面文本中的 🐱 emoji 自动替换为 `<img>` 标签
- TreeWalker 遍历文本节点 + MutationObserver 监听动态内容

### 25. 锁屏UI优化

**需求**：优化锁屏登录页的用户体验。

**详情**：
- **登录/注册tab切换**：替代原来的底部文字链接，选中态粉色渐变高亮
- **昵称输入上移**：从密码下方移到密码上方，符合从上到下填写习惯
- **密码自动提交**：输入满6位后自动触发登录，无需手动按"进入"
- **进入按钮高亮**：密码输满时"进入"按钮放大+亮度提示
- **登录欢迎语**：若localStorage存有上次昵称，自动填入并显示"欢迎回来，XXX 🐱"
- **轻提示**：非错误场景使用 `showPinHint()`，不抖动、不清空已输密码（昵称为空/格式不正确等）
- **"→"按钮改为"进入"**：中文文字更直观

### 26. 静态资源托管

**需求**：后端托管 `assets/` 目录，前端通过 `/assets/` 路径引用图片。

**详情**：
- `server.js` 新增 `app.use('/assets', express.static(...))`
- 图片部署与代码同仓库，无需额外CDN
